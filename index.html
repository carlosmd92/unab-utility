Consulta de Horarios UNAB

La utilidad ahora es un marcador (bookmarklet) que se ejecuta dentro de Banner. Así las consultas salen desde el mismo origen y Banner 9 no las bloquea.

El marcador

Este es el único marcador que necesitas (trae el panel desde este repo):

Horarios UNAB

Instalar en el computador

  1. Arrastra el botón azul “Horarios UNAB” a tu barra de marcadores.
  2. (Si no puedes arrastrar: crea un marcador nuevo, nómbralo Horarios UNAB y pega como dirección el código de la caja de arriba.)

Instalar en el celular

Chrome (Android)
  1. En cualquier página, toca ⋮ → ★ para crear un marcador.
  2. Abre ⋮ → Marcadores, mantén presionado el que creaste → Editar.
  3. Nómbralo Horarios UNAB y en URL pega el código (botón “Copiar código”). Guarda.
  4. Para usarlo: entra a Banner, escribe Horarios UNAB en la barra de direcciones y toca la sugerencia del marcador. (Chrome móvil bloquea pegar javascript: directo, pero el marcador guardado sí se ejecuta así.)
Safari (iPhone/iPad)
  1. En cualquier página toca Compartir → Añadir marcador.
  2. Marcadores → Editar → abre ese marcador, nómbralo Horarios UNAB y reemplaza la dirección por el código copiado. Guarda.
  3. Para usarlo: en la página de Banner, abre Marcadores y toca Horarios UNAB.

Cómo usarlo

  1. Inicia sesión en Banner (ssb8.unab.cl).
  2. En cualquier página de Banner, activa el marcador Horarios UNAB.
  3. Aparece el panel (arrastrable) con todo: búsqueda combinada, ver curso puntual y herramientas docente.
  4. Los resultados se abren en una pestaña nueva.
¿Por qué cambió? UNAB migró a Banner 9 (ORDS), que rechaza solicitudes desde otros sitios (CORS). Una página externa ya no puede consultarlo. El marcador corre dentro de Banner, así que es same-origin y funciona. La búsqueda usa el endpoint público p_get_crse_unsec; las herramientas docente usan tu sesión iniciada.

El panel vive en tool.js; el marcador lo carga desde GitHub Pages, así que cualquier cambio a tool.js se refleja solo.
